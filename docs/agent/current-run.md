# Current Run

No run is currently active. The orchestrator populates this file at the start of a run and clears / marks `done | failed` at its close.

```yaml
story_id: <none>
status: <none>
updated_at: <none>
owner_agent: ai-pipeline-rgr-orchestrator
worktree_path: <none>
branch: <none>
run_path: <none>
```

See `docs/agent/templates/current-run.template.md` for the populated schema.
